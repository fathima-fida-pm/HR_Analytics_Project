# HR Analytics Project Using SQL

## Project Overview
This project focuses on analyzing employee-related data using SQL and PostgreSQL to generate meaningful business insights.

## Business Problem
Organizations need to understand employee distribution, salary expenses, attendance, employee turnover, and performance to improve workforce management.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL
- Git and GitHub

## Database Tables
1. Employees
2. Departments
3. Attendance
4. Performance

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- JOINS
- Subqueries
- CASE WHEN
- Date Functions
- COALESCE
- SQL Views

## Key Business Insights
- Sales has the highest number of employees.
- Sales has the highest salary expenditure.
- 4 out of 14 employee records have an exit date.
- Sales has an average performance rating of 4.25.
- 5 employees achieved perfect attendance during the recorded five-day period.

## Conclusion
This project demonstrates how SQL can transform raw HR data into meaningful business insights and support data-driven decision-making.
